1. Introducción y Conceptos Fundamentales

Cómo la RAM organiza los datos y cómo interaccionan C y Python con ella.

Un apuntadorstrong> es una variable cuyo valor representa una dirección de memoria física o virtual en la arquitectura del sistema, donde se almacena otro dato u objeto (otra variable, estructura o función), en lugar de contener directamente un valor de datos primitivo.

Memoria RAM & Direccionamiento

La memoria RAM es una secuencia contigua de **celdas o bytes**, donde cada una posee una **dirección única** (expresada habitualmente en hexadecimal, ej: 0x7ffd9e42).

Dirección Hex Variable en C Valor en Byte
0x7FFE00 int x = 42; 00000000 ... 00101010
0x7FFE04 int *ptr = &x; 0x7FFE00

Stack vs. Heap

Stack (Pila): Memoria estática, de asignación rápida y gestión automática LIFO (Last In, First Out). Almacena variables locales y marcos de llamadas a funciones.
Heap (Montículo): Memoria dinámica de gran tamaño pero gestión manual (en C mediante malloc/free). Requiere mayor tiempo de gestión y puede sufrir de fragmentación.

C Operadores Clave de Memoria

  • &
    Operador de Dirección (Referencia): Devuelve la ubicación física exacta de una variable en la memoria RAM.
  • *
    Operador de Desreferencia (Indirección): Accede u opera directamente sobre el contenido almacenado en la dirección apuntada.

Python Modelo "Variables como Etiquetas"

En Python **no existen apuntadores explícitos** con desreferencia de memoria. En su lugar, todas las variables son **etiquetas o nombres que apuntan a objetos** creados en el Heap.

# Obtener la dirección interna del objeto

x = [1, 2, 3]

print(id(x)) # Muestra la dirección de memoria virtual (id)

Comparación de costo temporal y espacial en llamadas a funciones y estructuras dinámicas.

Paso por Valor vs. Paso por Referencia

Paso por Valor

Copia de Datos Complenta

Se duplica toda la estructura de datos en el Stack de la función receptora.

Copiar Estructura (1 MB):
Tiempo: O(N) | Espacio: O(N)
Paso por Apuntador / Referencia

Transferencia de Dirección

Sólo se transmite una dirección de memoria fija (4 u 8 bytes en arquitectura de 64-bits).

Transmitir Apuntador (8 bytes):
Tiempo: O(1) | Espacio: O(1)

Comparativa de Sobrecarga en Memoria (Arreglo de 10,000 elementos)

Paso por Valor (Copia completa) 40,000 Bytes extra
Paso por Apuntador (Dirección de memoria) 8 Bytes (Constante)

Estructuras Dinámicas

Sin apuntadores, las estructuras contiguas como vectores fijos imponen un tamaño máximo rígido o reasignaciones costosas $O(N)$.

Listas Enlazadas: Inserción/Eliminación $O(1)$ sin reasignar arreglos enteros.
Árboles y Grafos: Enlaces flexibles no lineales interconectados en el Heap.
La asignación dinámica (malloc) otorga control total sobre la longevidad de los datos.

5. Ejemplos Prácticos y Código

Patrones de código esenciales en C y Python con análisis paso a paso.

swap_pointers.c C 
#include <stdio.h>

// Intercambio mediante Paso por Apuntador
void swap(int *a, int *b) {
    int temp = *a; // temp guarda el VALOR de 'a'
    *a = *b;       // 'a' recibe el VALOR de 'b'
    *b = temp;     // 'b' recibe 'temp'
}

int main() {
    int x = 10, y = 20;
    swap(&x, &y); // Enviamos las DIRECCIONES de x e y
    printf("x=%d, y=%d\n", x, y); // Resultado: x=20, y=10
    return 0;
}

Análisis Técnico:

Si pasáramos swap(x, y) sin &, la función crearía copias locales en la pila y las variables originales x e y permanecerían inalteradas.

mutability_effects.py Python 
def modificar_lista(mi_lista):
    # Modifica directamente el objeto mutable referenciado
    mi_lista.append(99) 

def intentar_modificar_num(numero):
    # Reasigna el nombre local a un nuevo objeto entero
    numero += 10 

datos = [1, 2, 3]
valor = 5

modificar_lista(datos)
intentar_modificar_num(valor)

print(datos) # [1, 2, 3, 99] -> ¡El objeto original MUTÓ!
print(valor) # 5 -> ¡INMUTABLE! La reasignación no afecta el origen

Análisis Técnico:

Python evalúa como "Paso por Asignación de Objeto". Las estructuras mutables pasadas a funciones reflejan cambios externamente a menos que se cree una copia explícita (datos.copy()).

Reto de Programación: Aritmética de Apuntadores en C

Escribe una función en C que recorra e imprima los elementos de un arreglo de enteros utilizando **únicamente aritmética de apuntadores** (sin usar corchetes arr[i]). 

void imprimir_arreglo(int *ptr, int tam) {
    for (int i = 0; i < tam; i++) {
        // *(ptr + i) desplaza la dirección en i * sizeof(int) bytes
        printf("Elemento %d: %d\n", i, *(ptr + i)); 
    }
}

Nota Docente: Sumar 1 a un apuntador de tipo int* no suma un byte individual, sino la cantidad de bytes que ocupa el tipo de dato (típicamente 4 bytes para enteros).
